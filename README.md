# White Knuckle Archipelago

This mod is an archipelago implementation for White Knuckle.  
WARNING: This is still in active beta development, expect some minor issues to be present.

## What is randomized?
Locations:
- Entering unique rooms
- Purchasing Facility Upgrades
- Challenge mode medals

Items:
- Progressive buff perks that are the basis for logic
- Progressive perk machines that allow you to access the respective region's perks
- Progressive trinket slots
- Trinket unlocks
- Room progression unlocks
- Individual access for each challenge mode
- Access to the Training Sector
- Facility upgrades
- Roaches, starting roaches, and facility credits are filler

## How do i use this mod?

After installing the mod, you also will need the APWorld found on [the GitHub releases page](https://github.com/Makshime/White-Knuckle-Archipelago/releases), installing it through the standard procedure for custom APWorlds. You then can create a custom YAML using the Options Creator in the Archipelago Launcher.  
Once loaded, you can connect using the "connect" command in the console (Opened with shift + ~)
You can also change the client side options (such as deathlink or free disk vendors) using the changeclientoptions command

### Other Commands
disconnect - disconnects from the Archipelago Server.  
say - Sends the following message to the server client.

## Known Issues
- Disconnecting and reconnecting repeatedly will grant the roach and facility credit items again
